# GI-Flow Music

**Application Windows gratuite qui écrit des prompts en anglais pour les générateurs de musique par IA.**

Choisissez un ou plusieurs styles parmi 63 (dont Générique, Effets spéciaux et Soundtrack), ou décrivez
simplement la musique voulue en français : GI-Flow Music écrit un prompt complet (instruments, tempo,
ambiance, production), avec une durée réglable. L'application peut aussi analyser un fichier MP3, une vidéo,
une image ou des paroles pour en tirer un prompt. Elle utilise l'IA Google Gemini avec **votre propre clé API**
(gratuite).

## Télécharger

➡ **[Dernière version](https://github.com/web1099appli-lab/gi-flow-music/releases/latest)**

| Fichier | Usage |
|---|---|
| `GI-FlowMusic-Setup-x.y.z.exe` | Installeur (raccourcis Bureau et menu Démarrer) |
| `CGU-GI-Flow-Music.txt` | Conditions d'installation et d'utilisation |
| `SHA256SUMS.txt` | Empreinte pour vérifier l'intégrité du fichier |

Système : Windows 10 ou Windows 11 (64 bits). Gratuit. Connexion internet et clé API Gemini nécessaires.

## Installation

1. Téléchargez l'installeur et double-cliquez dessus.
2. Si Windows affiche « Windows a protégé votre ordinateur » (application non signée par un certificat
   payant), cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**.
3. Lisez les conditions et cochez **J'ai lu et j'accepte les conditions d'installation et d'utilisation**.
4. Au premier lancement, ouvrez **Réglages** et collez votre clé API Gemini, à créer gratuitement sur
   [aistudio.google.com/apikey](https://aistudio.google.com/apikey).

## Vos données

- Votre clé API est chiffrée sur votre ordinateur par Windows et n'est envoyée qu'à Google.
- Vos saisies et les fichiers analysés sont envoyés uniquement à Google, pour générer le prompt.
  Rien n'est envoyé à l'auteur de l'application.
- Réglages et historique : `%APPDATA%\GI-Flow Music`.
